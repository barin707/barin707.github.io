# Физио Журнал

Мобильное приложение для физиотерапевта: календарь записей, карты клиентов и каталог упражнений.

Работает как веб-приложение (PWA): открывается в Safari на iPhone и ставится на экран «Домой».
Данные хранятся только на устройстве, есть резервная копия в файл.

- `index.html`, `styles.css`, `app.js` - приложение
- `catalog.js` - каталог зон, рекомендаций и упражнений (можно дополнять)
- `sw.js` - офлайн-режим. После изменения файлов увеличь версию `CACHE`.
- `devices.js` - аппараты (HILT, УВТ, магнит, УЗ 1/3 МГц), показания по зонам и правила подбора
- `gcal.js` - синхронизация с Google Календарём (нужен свой OAuth Client ID, инструкция в разделе «Ещё»)
